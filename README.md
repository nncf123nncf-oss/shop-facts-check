# AIの文とお店の情報の照らし合わせ

お店の営業時間・休み・メニューの料金・住所・電話・メール・URL・やっていないことを一度登録しておき、
AIに書かせたお知らせなどを貼ると、文の中の時間・曜日・金額・連絡先に「登録と違う／同じ／確認／登録なし」の印が付きます。

- 見るのは登録した項目だけです。店名の書き間違い・誤字・登録していない事実は見つけられません
- 食い違いが見つからなくても、正しいとは限りません。最後はご自身の目で確かめてください
- 登録したお店の情報は、お使いの端末のブラウザ（localStorage）にだけ保存します。貼った文は保存も送信もしません（閲覧数を数えるアクセス解析だけ使っています）
- このページはAIにつながっていません
